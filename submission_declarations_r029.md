## Data availability

The study uses synthetic wideband BS--RIS--UE channel realizations generated by
the scripts in the accompanying reproducibility bundle. The generator,
configuration values, fixed seeds, table exporters, verification manifests and
machine-readable result summaries are publicly available at
<https://github.com/pengliangtian06-commits/ris-source-free-pilot-adaptation/tree/v1.0.2>.
The release family is archived at Zenodo under concept DOI
<https://doi.org/10.5281/zenodo.23118757>; the previous version record is
<https://doi.org/10.5281/zenodo.23118758>. The package contains synthetic data;
no measured-channel data are claimed.

## Code and model availability

The source-estimator and adapter implementations, experiment configurations,
table-generation scripts and verification scripts are included in the public
release at <https://github.com/pengliangtian06-commits/ris-source-free-pilot-adaptation/tree/v1.0.2>.
Source code is released under the MIT License; manuscript text, figures, tables
and generated result artifacts are released under CC BY 4.0. The current
paper-grade package reports locally regenerated CPU timings; they are
hardware-specific and should not be interpreted as a platform-independent
benchmark.
