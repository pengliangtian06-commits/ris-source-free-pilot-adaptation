# Release v1.0.0

This release archives the paper-grade reproducibility package for the current
CPU results. It contains the manuscript source, synthetic-channel generators,
baselines, result summaries, table and figure sources, verification records and
the bounded DOI search record.

The release is intended for reproducibility and review. It does not include
private host details, credentials, temporary LaTeX build products or stale
external CUDA logs. The current manuscript describes the recorded CPU artifacts
and keeps the controlled-simulation and negative-control limitations explicit.

The complete archive is `submission_package_r032.zip`. The Git tag for this
release is `v1.0.0`.
